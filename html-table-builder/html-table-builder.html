Select action — Map (text mode → fx)

              
              
            

            

            
Click the switch-to-text-mode toggle on the right of Map (icon top-right). Then click into the Map field, open the Expression editor (fx), and paste this concat(…) there — not directly into the field. The fx editor takes it as an expression, so the Select outputs one HTML row string per item; pasting plain text into the field instead makes Power Automate read it as JSON and split it into one field per character.

          


          

            

              3
              
Compose action — Inputs (fx)

              
              
            

            

            
Add a Compose action after the Select. Click its Inputs field, open the Expression editor (fx), and paste this. It builds the entire table — header plus join(…)'d rows — as one HTML string.

          


          

            

              4
              
Send an email (V2) — Body

              
              
            

            

            
In the email Body, insert the Compose action's Outputs from the dynamic-content picker (or paste the expression above). Do not use code view — a single dynamic value drops the whole table in as-is, so Power Automate can't hoist the rows out of the table (which is what left your <tbody> empty). Adjust the action name if your Compose isn't named Compose.
