How Model Sweep decides an object is unused

An object is used when it is referenced by an uploaded report or by model structure such as relationships, row-level security, hierarchies, or perspectives. DAX dependencies are followed transitively. An object marked used by unused is referenced only from another removal candidate, so those objects should be reviewed and removed as a group.

This is a static project scan. It cannot see reports, Excel workbooks, XMLA clients, or other consumers outside the uploaded folder, and dynamic references can be impossible to prove from text alone. Treat the result as a cleanup shortlist, keep a backup, and re-open the project in Power BI Desktop after any manual edit.
