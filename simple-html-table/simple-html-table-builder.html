Conditional Table Colourizer

Add value-based colours & logic to a Power Automate Select → Compose → Send email flow

Paste a JSON array of objects — the items your flow loops over (e.g. the output of Get items). Keys become columns; every row is used for the live preview.

How it works: a Select action builds one <tr> per item — each column value is wrapped in an if(…) rule that applies a coloured <span> inline. A Compose action wraps the rows in a complete table. The email body just references outputs('Compose') — no unescaping needed. Technique from tomriha.com.

Styling is applied as inline CSS on <table>, <th>, and <td> elements — compatible with all email clients including Outlook desktop. Zebra striping uses a <style> block with nth-child (Outlook web and most modern clients; not Outlook desktop).
