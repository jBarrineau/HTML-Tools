# HTML-Tools

A collection of single-page, client-side HTML tools — no installation, no dependencies, just open in a browser.

---

## Tools

### Power Automate

| Tool | Description |
|------|-------------|
| [Fast Filter](fast-filter/fast-filter.html) | Visual query builder for constructing Power Automate **Filter Array** expressions without writing code. |
| [Power Automate Expression Tester](power-automate-expression-tester/power-automate-expression-tester.html) | Test Power Automate Cloud Flow expressions against action output JSON with real-time evaluation, supporting full `@{…}` interpolation. |
| [Expression Scratchpad](power-automate-expression-tester/expression-repl.html) | A lightweight REPL for experimenting with Power Automate expressions, with function reference and history navigation. |
| [simple-select](simple-select/simple-select.html) | Visual builder for Power Automate's **Select Action** — map input fields to an output structure without writing code. |
| [Form Overlay Builder](form-overlay-builder/form-overlay-builder.html) | Upload a PDF screenshot, draw interactive form field overlays over it, and export JSON ready to import into a Power Automate flow. |

### Power Apps / Power Fx

| Tool | Description |
|------|-------------|
| [Power Fx Regex Lab](power-fx-regex-lab/power-fx-regex-lab.html) | Test and debug regular expressions using Power Fx syntax (`IsMatch`, `Match`, `MatchAll`) with real-time match highlighting and captured group display. |
| [Power Apps Timeline Viewer](power-apps-events-tracer/power-apps-events-tracer.html) | Upload a Power Apps trace JSON file and explore events in an interactive timeline with search, duration metrics, and response size details. |
| [Tidy Types](tidy-types/tidy-types.html) | Paste Power Fx records or tables and convert them into **User Defined Type (UDT)** syntax with automatic type inference. |

### SharePoint

| Tool | Description |
|------|-------------|
| [SP HTTP Request Builder](flow-sharepoint-api/flow-sharepoint-api.html) | Build copy-ready **Send HTTP Request to SharePoint** action inputs (Method, Uri, Headers, Body) for list item CRUD and `$batch` operations, with a visual OData query builder. |
| [OData URI Builder](odata-uri-builder/odata-uri-builder.html) | Visually construct OData query URIs for SharePoint Online — select fields, apply filters, and configure query parameters without memorising OData syntax. |
| [SharePoint List Schema Parser](get-sharepoint-list-schema/get-sharepoint-list-schema.html) | Step-by-step tool to extract a SharePoint list schema via the REST API and convert the XML response into compact, token-efficient JSON. |

### General

| Tool | Description |
|------|-------------|
| [RegexLab](regex-lab/regex-lab.html) | Interactive regex tester with real-time match highlighting, a built-in pattern library, and easy copy-to-clipboard. |
| [HTML Form Builder](new-form-builder/new-form-builder.html) | Drag-and-drop form designer for building responsive HTML forms, with export to HTML or Power Automate Flow JSON. |
| [Easy Color Picker](easy-color-picker/easy-color-picker.html) | Upload an image and click to pick and extract colors, with HEX, RGB, and HSL output. |
